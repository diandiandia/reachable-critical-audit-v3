# SYSTEM_DESIGN_V3_11 — Android 系审计（移动平台组件面/内核系）复盘设计缺陷修复

> 版本链：v3.10.2（2026-08-29，多媒体系列批次复盘）→ **v3.11（2026-08-29，Android 相关审计设计缺陷复盘）**。
> 缺陷修复版：不改变阶段骨架 R0-R6、不改变六门禁①-⑧判据语义、不改变队列数据模型主体。
> 背景审计：移动平台组件面（跨语言三明治结构目标）+ 内核系目标的审计实战。
> 复盘发现 7 项设计缺陷（R-A~R-G）→ 本版修复 7 项；全部过义务入库三问，无裁剪为不建项。

## 1. 问题域（R-A ~ R-G，7 项设计缺陷）

| 编号 | 问题 | 复盘案例（追溯） | 形态 |
|---|---|---|---|
| R-A | **信任边界几何缺「攻击者主体层级」维度**：DIRECT/ACROSS_BOUNDARY 二分把「同设备其他应用」（经导出组件/意图参数注入）与「远程攻击者」（网络字节）混为同一档——两者在利用难度、CVSS 基线、受影响构建类型限定、CVE 申报口径上完全不同 | 同批次内: 同设备异主体注入族（调试构建限定、上游已知）与远程内容族（全平台发布面）同为 ACROSS_BOUNDARY, 申报材料被迫手工区分口径 | 数据模型缺口 |
| R-B | **平台 API 行为契约无积累面**：平台 API 对恶意输入的固有处理语义（资产管理器 zip 条目查找拒绝上溯段、系统服务绑定+用户授权中介、剪贴板前台限制、直缓冲分配保证）4 次成为决定性裁决依据, 全部靠 agent 现场查证——知识不可积累不可复用 | 阻断/放行判定的关键依据每次重新发现; 证伪方向依赖 agent 自带平台知识（自带知识错误即误杀） | 知识供给缺口 |
| R-C | **「模板 → 实例化产物」面缺失**：R1 测绘对象是仓库代码, 但真实攻击面在模板/生成器产物（引擎自身清单零导出组件, 但模板产物导出）——部署布局义务查发布产物、scope snapshot 查源码树, 中间形态两头不覆盖 | 「零导出组件」的错误阻断论证靠复活者发现模板产物才纠正 | 供给面缺口 |
| R-D | **运行时版本条件分支无建模**：门禁模型 = 代码路径 + 编译开关, 但运行时版本判断（平台版本 API 级差异）与构建变体（调试/发布配置差异）既非编译开关也非配置门——同代码在不同设备版本/构建类型有不同攻击面 | 剪贴板限制在低版本 API 级不生效; 注入参数在发布构建被过滤而在调试构建放行 | 门禁维度缺口 |
| R-E | **初始化时序输入面无假说**：H1-H7 无「初始化前注入/启动时序窗」结构化假说——启动参数/初始化前到达的输入在安全配置生效前被消费的面, 两批次重复命中靠 R2 自由发挥覆盖 | 启动窄窗崩溃面 + 冷启动注入面 (两个批次各自命中) | 假说体系缺口 |
| R-F | **跨语言逻辑镜像面完整性无机制**：同一逻辑面在多语言实现（通道编解码四实现族）靠 R2 恰好覆盖; R1 mirror_pairs 只管同文件跨域, 不管同逻辑跨语言——漏掉一个语言实现即漏掉一个 sink 族 | 本批次最高价值家族之一（四实现同逻辑面全部独立成候选）靠假设生成恰好覆盖, 无完整性保障 | 完整性缺口 |
| R-G | **审计树 ≠ 部署物差异无声明机制**：审计源码树与真实部署物差异（依赖未物化、生成物缺失、外部构建面）靠主代理手工声明; 「树外不可验证」类 drop 的可靠性依赖该声明 | 未物化依赖面（解码器执行主体）全程靠手工注记; 内核系 OEM 构建差异同理 | 声明缺口 |

## 2. 修复策略（7 项 REQ，详见 REQ_V3_11.md）

1. **攻击者主体层级字段**（R-A）：candidate 新增 `attacker_tier` 枚举 `same_process | same_device_cross_app | system_broker | remote`（可选, 缺省按 trust_boundary 推导）; R3 步骤 3 判定时 verifier 填写; 报告问题清单按 tier 分列渲染; 申报口径按 tier 取值
2. **平台 API 行为契约库**（R-B）：checklist_library 新增 `platform_api_contracts` 清单族（与 platform_trust_models 平级, 条目含实证来源 source 必填防幻觉契约）; 复用 v3.10.2 注入管线（detect_platforms → 三层 prompt）
3. **模板产物面登记**（R-C）：R1 测绘任务书「生成器/模板产物面」指引段（按构建形态分派）; entry_points 可选标记 `instantiated_artifact`; R3 步骤 0.5 构建包含性按「模板 → 实例化产物」链判定
4. **运行时版本条件检查项**（R-D）：verifier 步骤 4 阻断检测清单加「运行时版本条件」项（版本 API 级判断/构建变体差异对攻击面维度的影响）——提示级, 无自动检测（语言习语过杂）, evidence 渲染 + 主代理确认
5. **H4 初始化时序子项**（R-E）：H4 检测要点加「初始化时序注入面」（启动窄窗/冷启动注入/初始化时序竞态）
6. **逻辑镜像提示**（R-F）：R1 merge 输出 `mirror_candidates` 提示（语义相似 + 跨语言, 不自动组族——主代理裁决）; R2 假设生成任务书加「逻辑镜像枚举」条款
7. **审计树差异声明**（R-G）：R0 scope snapshot 扩展「构建差异声明」段（构建清单声明的依赖/生成物 vs 树内物化状态）; 报告附录 B 渲染「审计树与部署物差异」段

## 3. 义务入库三问（新义务逐条）

| 新义务 | ①触发条件 | ②消费者 | ③案例支撑 |
|---|---|---|---|
| attacker_tier | R3 步骤 3 判定（verifier 填写, 缺省推导） | 报告分列 / 申报口径 / CVSS 取值 | 同批次两类 ACROSS_BOUNDARY 口径混淆 |
| platform_api_contracts | 目标含对应平台组件（信号驱动, 零注入兜底） | 三层对抗复核 prompt | 4 次决定性裁决靠现场查证 |
| 模板产物面登记 | 仓库含模板/生成器目录（路径信号） | R1 测绘 / R3 步骤 0.5 | 零导出组件的错误阻断论证 |
| 运行时版本检查项 | verifier 步骤 4 恒（提示级） | verifier 证据 / 报告前提列 | 低版本无剪贴板限制; 发布构建过滤 |
| H4 时序子项 | H4 恒（假说描述扩展） | R4 agent / gate ④ | 启动窄窗 + 冷启动注入两批命中 |
| 逻辑镜像提示 | language_inventory ≥2（merge 输出） | 主代理 merge 复核 / R2 条款 | 四实现同逻辑面家族 |
| 审计树差异声明 | 构建清单含未物化依赖（R0 检测） | 报告附录 B / drop 理由可靠性 | 未物化依赖面手工注记 |

## 4. 明确不做（义务棘轮防护）

- 不改 reachability_type 枚举（attacker_tier 为独立字段, 二分语义保留）。
- 逻辑镜像不做自动组族（语义相似度判定不可靠, 提示级交主代理裁决）。
- 运行时版本不做自动检测（语言习语过杂, 提示级 + 主代理确认）。
- 不加新门禁（六门禁①-⑧判据语义不变）。
