# SYSTEM DESIGN V3.21 — 变更边界不变式与模块影响面（2026-09-03）

## 变更边界不变式

1. **阶段骨架不变**：R0-R6 零改动（条款落在既有节内）。
2. **六门禁①-⑧判据语义不变**：矛盾扫描条款是报告定稿前的**主代理义务**，
   不进门禁判据；无新门禁名。
3. **队列数据模型零改动**：无新字段（empirical_feasibility 为笔记级产物，
   不落 schema、不进队列）。
4. **零新工具**：矛盾扫描用固定 grep 清单（文本级），不建扫描器；
   零新阶段、零新强制 schema。
5. **跨 skill 边界**：skill-optimizer 侧只改 SKILL.md 阶段 0 一段
   （DDL 语义强化），不动其闭环总览/阶段 1-7。

## 风险与回退

- **风险**：条款级义务无机械强制——v3.20 教训"提示词不足以保证执行"适用
  于子代理行为偏差；本版三义务的消费者是**主代理与用户**（编排层），
  按容忍契约优先（v3.15 D-6/D-8 先例）不做字段强制；若未来审计复现同类
  迟到裁决，再升级机械校验（条款中留"复现即升级"注记）。
- **回退**：三处改动互相独立（recorder 文案 / SKILL.md 条款 / skill-optimizer
  条款），任一 revert 不破坏另一侧。
